# FusionStructure Brandbook

## Alcance
Este repositorio contiene exclusivamente el brandbook y los activos de identidad de FusionStructure.

## Reglas
- No introducir landing, solver, CAD, BIM ni motores de cálculo.
- Aqua estructural es el acento de marca; las señales técnicas conservan sus colores semánticos.
- Los activos generados deben salir de `brandbook-site/scripts/build-brand-assets.mjs`.
- Preservar accesibilidad, responsive y modo día/noche.
- Ejecutar `npm run brand:assets`, `npm run lint` y `npm run build:pages` antes de fusionar.
